## STRIDE Assessment

- **Spoofing** — Strong. Progressive per-IP lockout with anti-spoof buckets; `custom-server.js:66-71` deletes client-supplied `x-9r-real-ip`/`x-forwarded-for`/peer-token headers and re-stamps with a per-process random token; CLI-token and HMAC checks use `timingSafeEqual`. Default password "123456" is locality-gated: remote fresh-install logins require a one-time setup code printed only on the host (`src/app/api/auth/login/route.js:60-92`); sensitive re-auth paths refuse default-password fallback entirely (`verifyDashboardPasswordAgainstStoredHash`).
- **Tampering** — Good. Repos use parameterized queries; the one string-built SQL (`ATTACH DATABASE` in `src/lib/db/backup.js:42-44`) uses app-controlled paths with quote-escaping; `ALTER TABLE` in `migrate.js` uses internal migration constants. XSS gap limited to the changelog sink (Finding 1). No command injection with user-controlled input found — all `execSync`/`spawnSync` template literals interpolate internally-sourced pids/ports/app paths.
- **Repudiation** — Adequate. Login failures/budget blocks logged with masked keys; observability table exists; note it is intentionally excluded from DB backups.
- **Information Disclosure** — Good. Logs mask API keys (`maskKey`/`maskApiKey`); MITM root CA key written `0600` in `0700` dir; JWT secret auto-generated 32-byte random at `0600` when env unset (no hardcoded fallback). `requireLogin` defaults to `true` (`settingsRepo.js:30`). cookies.txt token verified expired (Finding 3).
- **Denial of Service** — undici WebSocket process-crash reachable via Node-bundled copy + provider-configured Live endpoints (Finding 2); lockout state volatility (Finding 7). No unbounded unauth endpoints found: `/api/health`, `/api/version`, `/api/init` are cheap; SearXNG/chat/embeddings/fetch/video handlers all enforce `requireApiKey` + key budgets when enabled.
- **Elevation of Privilege** — Good. `dashboardGuard.js` path classes (public / protected / always-protected / local-only) correctly fence process-spawning and host-secret routes (`/api/tunnel/*`, `/api/cli-tools/*`, `/api/mcp/`) behind localhost; disabling `requireLogin` is an explicit user opt-out that opens dashboard APIs on the bind address — on a shared VPS this must stay enabled.
